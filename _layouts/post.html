댓글

현재 댓글은 GitHub Issues에 공개됩니다. Utterances 정책상 댓글을 게시하려면 GitHub 계정 로그인이 필요합니다. 로그인 없는 익명 댓글은 별도 서버·스팸 방지 서비스 연결이 필요합니다.

댓글을 보려면 JavaScript와 utteranc.es 연결을 허용해 주세요.

익명 댓글 연결 준비

로그인 없는 댓글을 사용하려면 운영자가 외부 댓글 서버를 연결해야 합니다. 아래 특수기호 확인란은 스팸 방지용 입력 UI입니다.

댓글이 보이지 않나요? 네트워크 연결과 브라우저의 콘텐츠 차단 설정을 확인해 주세요.

사이트 운영자를 위한 댓글 설정

댓글을 사용하려면 공개 댓글 저장소에서 Issues를 켜고 utterances GitHub 앱을 해당 저장소에 설치해야 합니다. 설정이 완료되지 않으면 댓글이 표시되지 않을 수 있습니다.
